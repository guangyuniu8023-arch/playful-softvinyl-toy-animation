# 萌趣软胶玩具动画提示词模板

使用前先从 `style-guide.md` 提取任务所需规则。花括号字段由用户输入、参考分析或上游规格填写；缺失的输出规格保持未指定，不擅自补入固定模型、尺寸、画幅、时长、镜头数或帧率。

## 通用参考职责块

```text
参考职责：
- reference-01-overall-style：只负责明亮实体微缩摄影、软胶与日常事故反差的整体风格。
- reference-02-character-design：只负责多角色样本共同体现的 2–3 头身、大轮廓、大块面、厚塑胶、简单关节、分色逻辑及萌呆气质谱系；不得继承其中任何单个形象的物种、五官、服装或身份。
- reference-03-scene-environment：只负责桌面室内模型、冷白顶光与暖实用光、手工板材边缘；不继承其高道具密度。
- reference-04-composition-camera：只负责玩具视线高度、平视略低近摄、提示物强调与浅景深；不锁定具体角色或路径。
- 用户上传内容参考：{逐张写身份、服装、场景、构图、动作起点或关键道具职责}
优先级：用户明确硬约束 > 身份与内容参考 > 构图参考 > 风格参考。
```

只使用实际存在的参考项；没有某张输入时删除对应行。

## 全局风格块

```text
将{主体与关系}制作成萌趣软胶玩具动画：角色保持 2–3 头身，外轮廓优先，细节相对常规收藏模型简化约 30%，由少量圆钝大块面构成；气质可在天真、迟钝、木讷、困惑、一本正经、笨拙与古怪亲和之间选择，不要求统一甜美可爱，也不复刻 reference-02 中任何具体形象。材质是复古软胶/早期 PVC：塑胶厚、略蜡质、半哑光，简单分色，轻微喷涂不均，可见粗朴分型线与较大简单关节。场景是较明亮、稍现代、简洁的桌面实体模型；相对繁复微缩布景减少约 35%–40% 道具，只用必要的柜体、置物架、收纳箱、门框、工作台和关键互动道具建立空间。板材边缘厚、圆钝、略不完全笔直，带轻微手工切割与喷漆偏差。冷白顶光为主，少量柔和暖色实用光辅助，色块简洁，近摄浅景深保留实体微缩尺度。喜剧来自严肃工作姿态与{琐碎失误}的反差。
```

## 最终自检模板

```text
- 参考职责是否逐张明确，是否把角色、地铁、雨伞等示例误写成硬锁？
- 角色是否为 2–3 头身、轮廓优先、细节简化约 30% 的大块面软胶？
- 是否保留厚、略蜡、半哑光塑胶、简单分色、喷涂偏差、分型线和大关节？
- 场景是否明亮、稍现代、简洁，并相对繁复布景减少约 35%–40% 道具？
- 是否用少量大体块与关键互动道具建立清楚因果，并保留留白？
- 光线是否为冷白顶光主导、少量柔暖实用光，且没有 HEX 色板？
- 图生图是否分别写明必须保留、允许改变和具体重绘规则？
- 每个视频镜头是否都有起始状态、主体动作、环境响应、镜头运动、结束状态和连续性？
- 动作是否少而清楚、有大轮廓跳变、硬塑料重量、短促爆点和安静停顿？
- 声音是否低密度、材质对应、同步落点，并在喜剧停顿中留白？
- 是否排除了树脂精雕、复杂机械、密集鳞片、建筑锐边、过度破败、顺滑融化和无意义抖动？
- 是否避免写死模型、分辨率、画幅、时长、镜头数和帧率？
```
